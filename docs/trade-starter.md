# Trade starter profile

New solver profiles start in **Compare multiple rewards** mode with these priorities.

| Reward | Points | When points are awarded |
| --- | ---: | --- |
| Exceptional Gem | 10 | Once per completed combo |
| Item Rarity | 4 | Once per completed combo |
| Dreadmaidens' Sacrament | 2 | Once per completed combo |
| Additional Currency Items | 3 | Per confirmed regular reward icon |

The weights are provisional priority points. They are independent of market prices and expected profit. An unconfirmed currency icon needs review before it can earn points.

To apply the starter to an existing profile, open **Reward priorities** and select **Use trade starter**. This enables comparison, sets the four weights above and adds any missing priorities. It keeps other priorities, modifier filters and personal reward templates. If the result would exceed 30 priorities, remove enough priorities before applying the starter.
