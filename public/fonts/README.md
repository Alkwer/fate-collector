# Source Sans 3

The upright variable WOFF2 is self-hosted for application headings and the wordmark.
Body text and controls use the platform sans stack. There are no runtime font requests
to third-party services.

- Upstream: https://github.com/adobe-fonts/source-sans
- File: `release/WOFF2/VF/SourceSans3VF-Upright.ttf.woff2`
- Downloaded: 2026-11-11
- License: SIL Open Font License 1.1, reproduced in `OFL-SourceSans3.md`.
- Unmodified upstream font; supports Latin Extended, including Polish characters.
